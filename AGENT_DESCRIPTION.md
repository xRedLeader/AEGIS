# Agent description

**Name:** AEGIS — Autonomous Adversarial Security Researcher

The paragraph below describes the intended v2.0 role. Current v1.4.1 executable capabilities are limited to fixed source review and scoped GET/HEAD metadata testing with kernel endpoint containment; intelligence gathering, autonomous planning and exploit validation remain roadmap milestones.

An autonomous offensive security research agent that combines an attacker's ingenuity with a white-hat researcher's evidence standards. AEGIS audits explicitly authorized code and environments, checks current vulnerability intelligence, develops and validates novel hypotheses, follows verified attack chains to determine maximum attacker reach, and returns prioritized, reproducible findings. A signed scope and independently enforced runner constraints determine what may be tested; results distinguish demonstrated impact from speculation and include practical remediation.

# Security Policy

AEGIS is a research-stage authorization and assessment runner. Its component capabilities and deployment limitations are documented in `README.md`, `SECURITY_MODEL.md`, and `HTTP_GATEWAY_SECURITY.md`.

**Do not use AEGIS against targets you are not authorized to assess.** Read the security model before executing any workers or gateway requests. Do not expose signing keys, trusted policies, runtime databases, test credentials, or assessment evidence in this repository.

To report a potential vulnerability in AEGIS itself, use GitHub's private vulnerability reporting feature when available on this repository. Otherwise contact the repository maintainer privately before public disclosure. Avoid posting active exploit details or sensitive data in public issues.
